## Interpretation for this user (inference, not respondents' consensus)

1. The credible split is not simply AI versus no AI. Some expect dramatically less line-by-line human code reading; others warn that early-career engineers lose mental models. Both still require ownership of outcomes and credible validation.
2. For someone who cannot yet confidently write loops/functions, understanding inputs, state, conditions, requests and failures remains necessary to define checks or reject an agent's wrong explanation. Seniors' sophisticated verification workflows are not evidence that fundamentals can be omitted.
3. Repair one bounded user flow, record its reproducible bug, attempt a small change, explain it aloud, verify it in both themes/mobile, then obtain a human review. This generates defensible collaboration evidence faster than adding unrelated features.
4. Likes identify reach, not accuracy or local hiring demand. This sample is disproportionately English-language public AI-writing enthusiasts; it cannot estimate internship availability, salaries, or probabilities of employment.
