# DealFlow — catalog reference adaptation

The owner selected uxui. Raha’s E-commerce Product Management Dashboard UI on Behance (project 244209055). Reference images were inspected from the owner’s saved HTML and companion assets on 2026-11-02.

White sidebar and panels sit on #f1f0f6. Violet #6554e8 identifies selected navigation and primary actions. Body text #192137, secondary #59657a, lines #e5e6ed. Pale green and amber convey status. No decorative glows or gradients.

Nunito Sans is a visual approximation of the reference’s compact humanist typography; the original font was not identified. System Segoe UI is the fallback. Main copy 13–14px; product titles 14px/1.45 at 750; prices 24px/800. Panels use 14px radii and controls 7px.

Preserve DealFlow’s image-led card review grid, editor, inspector, publishing, channels, rules, video and settings functions. This adaptation changes styling, not backend behavior. The generated concept is illustrative and separate from rendered implementation screenshots.
