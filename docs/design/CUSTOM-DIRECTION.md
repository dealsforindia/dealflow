# Custom DealFlow direction

Mode: Operate. Existing populated dark review deck is the anchor; no marketing hero, no borrowed storefront identity.

## Direction contract
THESIS: A product-evidence workbench for a curator who must see offers and act quickly. Keep the image-led grid; organize secondary machinery rather than displaying equal-weight badges.
OWN-WORLD: Graphite slab surfaces with quiet inset tool rails, restrained jade publication controls and amber price evidence. Readable sans typography, crisp bespoke mark, neutral line icons. No animated halos or gradient-text prices.
STORY: Orient to source/status, inspect product/price, tune post, choose destination, publish with explicit pending/accepted/failed outcome.
FIRST VIEWPORT: Compact fixed sidebar; search/actions and status/filter controls; full-width responsive four-column deal deck. Image, readable title, price and footer share consistent alignment. Inspector remains an optional working mode. Secondary screens use the same control/field/dialog language, shaped for their job.
FORM: Owner-provided screenshot and existing application govern composition; custom, not a dealt theme. seed: none (explicit reference).
FINISH: source checks, rendered desktop/phone screen matrix, functional fixture regressions and independent review; report limitations. No live posts or deployment.

## Files
Edit existing application/component styles and affected view markup. New reusable token stylesheet. Delete no application functionality. Preserve endpoints, fields and handlers; repairs documented separately. Generated concept images are proposals, not pixel-exact implementation authority.
